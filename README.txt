# Tapri Wala — Free Website Starter

## Files
- `index.html` — website structure
- `style.css` — complete responsive design
- `script.js` — player + playlist interactions
- `assets/tapri-wala-visual-reference.png` — visual concept reference

## Run it
Double-click `index.html` to preview it in a browser.

## Make it live for free
Recommended: GitHub Pages.

1. Create a free GitHub account.
2. Create a new public repository named `tapri-wala`.
3. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
4. Go to Settings → Pages.
5. Select Deploy from branch → main → / (root).
6. Save. GitHub will give you a free `.github.io` website URL.

## Music
The player is intentionally left in demo mode. Old Hindi songs are copyrighted, so do not upload/stream commercial songs unless you have the required rights/licence.
When your own YouTube/Spotify channels are ready, replace the placeholder links in `index.html`.
